# Claude project entry point

Read and follow [AGENTS.md](AGENTS.md) before working in this repository. It is the shared project policy for both Claude and Codex; the same English-only documentation and comment rule applies.

Then read, in order:

1. [_Wiki/current-state.md](_Wiki/current-state.md).
2. [_Wiki/index.md](_Wiki/index.md).
3. [_Wiki/maintenance.md](_Wiki/maintenance.md).
4. The topic pages, decisions, and open questions relevant to your task.

Before handing work back, update the relevant wiki pages and append the task's evidence and verification to [_Wiki/log.md](_Wiki/log.md), as required by `AGENTS.md`. Do not keep a separate Claude-only project memory that conflicts with the shared wiki.
